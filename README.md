# ForensiX-AI

Project structure for the ForensiX-AI forensic analysis application.

## Backend

- `backend/collectors/` - Data collection components
- `backend/processing/` - Evidence processing components
- `backend/integrity/` - Integrity and validation components
- `backend/ai/` - AI-assisted analysis components
- `backend/database/` - Database integration components
- `backend/app.py` - Backend entry point

## Other directories

- `frontend/` - Frontend application
- `tests/` - Automated tests
- `data/` - Local project data
